# DDG

Pick how much storage you want to use. Get an offline collection of practical knowledge, maps, software, AI models, and culture that fits. Add space later and the collection grows without throwing away what you already downloaded.

The bigger idea is what happens across many users. Everyone gets useful local coverage, but qualified alternatives are deliberately spread across different drives. That preserves more knowledge and different perspectives, and makes the population less dependent on every choice in a single curator's bundle being right.

Existing readers, model runtimes, editors, and agent harnesses make the material usable. DDG would provide the catalog, selection policy, verified acquisition, and maintenance that connect those tools. Users' own work stays outside the managed archive.

**Read the [full proposal](PROPOSAL.md).** It explains the experience, concrete examples, existing projects, product requirements, candidate algorithms, independently workable components, and the decisions still open.

This is a design-stage project. Windows, macOS, and Linux are equal desktop targets; Android can follow later. Storage budgets and selection policies are configurable, with defaults to be evaluated empirically.
